## Abstract (verbatim)
Ontology learning from text remains challenging despite significant progress in Large Language Models (LLMs), which can hallucinate domain terms, produce inconsistent formats, and favor hierarchical over associative relations. In the LLMs4OL 2026 Challenge, we address both the End-to-End Flagship Task (Task A) and Ontology Extension Reuse Task (Task B) using an offline retrieval-augmented few-shot prompting pipeline. Our system employs Qwen2.5-14B-Instruct with all-MiniLM-L6-v2 for demonstration retrieval, selecting the top-5 examples for Task A and top-2 for Task B. A left-truncated context-windowing strategy preserves task instructions within long prompts. For Task B, generated triples undergo deterministic vocabulary-constrained filtering, retaining triples when at least one endpoint belongs to the sample's closed term/type vocabulary and removing duplicates of the initial ontology. The approach achieves Semantic Graph Similarity of 0.8692, Term-Typing F1 of 0.9200, and Taxonomy Discovery F1 of 0.8540 on Task B, while Task A achieves 0.7416 Semantic Graph Similarity. However, no non-taxonomic relations are extracted, highlighting limitations of closed, taxonomy-oriented relation vocabularies.

## Method recipe (reproduction-critical)
1. Offline RAG few-shot prompting.
2. LLM: `Qwen2.5-14B-Instruct`.
3. Retriever: `all-MiniLM-L6-v2`; top-5 demos (Task A), top-2 (Task B).
4. Left-truncated context windowing so task instructions survive long contexts.
5. Task B post-process: vocabulary-constrained filter — keep triple if ≥1 endpoint ∈ sample term/type inventory; drop triples already in initial ontology.
6. Relation bias: system is taxonomy-oriented; closed vocab filters suppress non-taxonomic predicates.

## Findings worth promoting
- **Semantic Graph Similarity is the primary 2026 leaderboard metric** (not just micro-F1). Implement `2026/metrics/graph_similarity.py` faithfully before comparing systems.
- RAG + constrained decoding/filtering is a strong 2026 baseline without full finetuning — matches OntoLearner phase-2 integration spirit.
- Failure mode: **zero non-taxonomic relations**. Any 2027 reproduction targeting Task A completeness must open the relation vocabulary or explicitly model non-taxonomic RE; otherwise graph similarity plateaus.
- Task B (0.8692) ≫ Task A (0.7416): giving a partial ontology + closed type inventory is much easier than open E2E construction.
- Use vocabulary constraints from the sample itself (terms/types fields) — these are provided even when `terms` is often empty; rely on `types`.
